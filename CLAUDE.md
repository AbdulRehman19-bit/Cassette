# Cassette — project notes

"pytest for agents": records an AI agent's runs (model + MCP tool calls) into cassette files, replays them in CI, diffs trajectories, asserts rules (incl. prompt-injection), reports as HTML + PR comment. Full spec: `docs/SPEC.pdf`. Plan: `docs/PLAN.md`.

## Goals
Record/replay over MCP (stdio, then Streamable HTTP) · trajectory diff (tools, args, results, output, tokens, cost, latency) · deterministic assertions · static HTML report + PR comment · live ChangelogCat demo agent.

## Non-goals (4 weeks)
No hosted dashboard/DB/auth · no per-provider SDK adapters (MCP is the tool boundary; one thin model wrapper) · ~5 attack fixtures only · no multi-server contract testing · no sandboxed code execution · no LLM-as-judge in core.

## Stack (backend is Python — switched from the spec's TypeScript on 2026-11-06)
Python >=3.11, uv, hatchling, pytest + pytest-asyncio, ruff, mypy (strict), pydantic v2, pyyaml, click, official `mcp` SDK (pin <2), `anthropic` (primary) / `openai` (second adapter), stdlib `difflib` for text diffs. The HTML report is generated by Python as one self-contained file (inline CSS/JS), no Node toolchain. Releases: PyPI (`cassette-cli`; the `cassette` command), Action as a composite action that installs it.

## Layout
- `src/cassette/cassette/` — cassette schema, store, normalization, trace→cassette builder
- `src/cassette/proxy/` — MCP proxy (record: forward+log; replay: answer from cassette)
- `src/cassette/replay/` — matcher + replay backend
- `src/cassette/model/` — model wrapper (`maybe_wrap_model`) and offline model replay
- `src/cassette/{config,trace,runner,cli}.py`
- later: `differ/`, `assertions/`, `report/`
- `action/` — GitHub Action
- `examples/changelogcat/` — demo agent (`python -m changelogcat`), its `cassette.yaml`, `cassettes/`, `attacks/`
- `tests/` — pytest suite incl. e2e gate test with a fake MCP server + fake agent (`tests/fixtures`)
- `docs/` — spec, plan

## How a run works
The agent is started with `MCP_<SERVER>_COMMAND` / `MCP_<SERVER>_ARGS` pointing at `python -m cassette proxy ...`, so its MCP traffic goes through Cassette. The proxy (separate process) and the model wrapper (in the agent process) both append to a shared JSONL trace (`CASSETTE_TRACE`); the runner folds it into a cassette. Real-server command/env reach the proxy via a temp `--spec` file, never argv.

## Determinism rules
Temperature 0 + fixed seed where the provider supports it (the Anthropic Messages API, Python SDK 2.6 and TS SDK 1.5 alike, exposes no temperature param, so Anthropic runs rely on tolerant matching) · strip/placeholder volatile fields (timestamps, IDs, key order) before diffing · configurable `tolerance` ignores whitespace/key-order arg changes · fail on tool-level changes by default; compare output text by similarity, not equality · captured agent stdout has CRLF normalized to LF.

## Run modes
`record` live model+tools · `replay` (CI default) live model + recorded tools · `replay --offline` recorded model + tools.

## Working rules
- Commit and push after every step. Do NOT add Co-Authored-By lines.
- Pin MCP SDK version; keep transport code in one module.
- Fixtures use only placeholder domains (`evil.example`) and fake canaries.
- Never open red-team PRs on others' repos without explicit permission.
- Windows is a first-class dev platform: force UTF-8 on CLI output, normalize CRLF, avoid f-string quote reuse (3.11 compat).
- Check: `uv run ruff check src tests examples && uv run mypy && uv run pytest -q`.
